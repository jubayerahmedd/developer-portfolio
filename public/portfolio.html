My QA Process

The same five steps on every feature, so nothing reaches users untested.

  1. 01

    Plan

    Read requirements, list risks and write test cases.

  2. 02

    Test

    Run manual and automated tests on web, mobile and API.

  3. 03

    Report

    Log clear bugs with steps, evidence and severity.

  4. 04

    Retest

    Verify fixes and run regression around them.

  5. 05

    Release

    Sign off with confidence, then watch for anything new.
